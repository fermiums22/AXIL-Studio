# AXIL Studio

Публичный веб-интерфейс настройки наушников. Основной экран — телефон.
Тема тёмная, основные акценты зелёные; касания L/R и центральное нажатие джойстика
подсвечиваются оранжевым градиентом с плавным затуханием. Зарядка показывается молнией
внутри батареи. Сохранять эти состояния и адаптацию к узким экранам.

- Здесь допускаются страница, исходники оформления и собранная библиотека связи.
  Исходники протокола, BLE/OTA и source map хранить только в закрытом репозитории.
  Не добавлять SDK, исходники прошивки, реальные образы, дампы, журналы устройств,
  закрытые документы, ключи, токены, пароли или абсолютные пути разработчиков.
- Сейчас интерфейс — интерактивный макет по эскизу пользователя. Демонстрационные
  значения явно помечать. Не изображать отправку команды или успех прошивки.
- Подключение управления выполняется следующим этапом через собранную библиотеку.
- Исходный HTML — `src/index.html`, приложение — `src/main.ts`, стили — `src/styles.css`.
  `npm ci`, затем `npm run build` проверяют TypeScript и создают автономный `index.html`
  в корне. Генерируемый файл не редактировать вручную.
- Сборка не коммитит и не публикует изменения. Для GitHub Pages сохранять готовый
  `index.html` вместе с исходниками; страница не должна зависеть от закрытой репы.
- Перед выдачей проверять телефонный и настольный экран, отсутствие горизонтальной
  прокрутки, вкладки, ползунки и выбор файла. Не обращаться к устройствам при проверке макета.
