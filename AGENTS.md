# AXIL Studio

Публичный веб-интерфейс настройки наушников. Основной экран — телефон.
Тема тёмная, основные акценты зелёные; касания L/R и центральное нажатие джойстика
подсвечиваются оранжевым градиентом с плавным затуханием. Зарядка показывается молнией
внутри батареи. Сохранять эти состояния и адаптацию к узким экранам.

- Здесь допускаются страница, исходники оформления и собранная библиотека связи.
  Исходники протокола, BLE/OTA и source map хранить только в закрытом репозитории.
  Не добавлять SDK, исходники прошивки, реальные образы, дампы, журналы устройств,
  закрытые документы, ключи, токены, пароли или абсолютные пути разработчиков.
- Интерфейс подключён через собранную библиотеку. Показывать только подтверждённые
  значения; неподдерживаемые и устаревшие данные обозначать явно. Не изображать
  отправку команды, измерение микрофона или успех прошивки без ответа устройства.
- Ключ открывает зашифрованный WASM в памяти браузера. Не сохранять ключ в файлах
  проекта, URL, localStorage или sessionStorage. Публичны только ciphertext и
  собранный JS; исходники библиотеки и открытый WASM сюда не добавлять.
  Форма пароля поддерживает встроенный менеджер браузера через стабильные
  username/current-password; предлагать сохранение только после успешной проверки.
  Отказ или отсутствие Credential Management API не должны мешать открытию доступа.
- Возможности запрашиваются у устройства; номер приложения 2.0.0 не является
  критерием поддержки новых функций. Старое OTA доступно без новых capabilities.
- Во время OTA исключать управляющие команды и поллинг. Сохранять числовой код
  ошибки устройства: выводить этапы и диагностику
  в обычную Console, поддерживать локальное сохранение её текста. Не писать
  пароль и содержимое образа. Ожидание блока не называть финальной проверкой.
  Повторная отправка тех же байтов не должна увеличивать процент передачи.
  Просмотр и сохранение Console доступны во время OTA. Ошибка или отключение
  не означают успех; нужно подтверждение валидации устройства. Выбор устройства,
  запись, мониторинг MIC и консоль запускаются явным действием пользователя.
- Исходный HTML — `src/index.html`, приложение — `src/main.ts`, стили — `src/styles.css`.
  `npm ci`, затем `npm run build` проверяют TypeScript и создают автономный `index.html`
  в корне. Генерируемый файл не редактировать вручную.
- Сборка не коммитит и не публикует изменения. Для GitHub Pages сохранять готовый
  `index.html` вместе с исходниками; страница не должна зависеть от закрытой репы.
- Перед выдачей проверять телефонный и настольный экран, отсутствие горизонтальной
  прокрутки, вкладки, ползунки, ключ, выбор файла и отключение. Автономные проверки
  используют подставной транспорт; реальное устройство подключается по запросу пользователя.
