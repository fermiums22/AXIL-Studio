# AXIL Studio

**[Открыть AXIL Studio](https://fermiums22.github.io/AXIL-Studio/)**

Страница настройки наушников в тёмной теме, рассчитанная прежде всего на телефон.
Сейчас подготовлен интерактивный макет: значения демонстрационные,
команды на устройство не отправляются. Подключение управления — следующий этап.

На вкладке **Remote** находятся HT, уровень и баланс каналов, громкость музыки,
индикаторы MEMS и заряда, Sleep, выбор прошивки и Update.
На вкладке **Console** — поле ручного ввода команд и журнал макета.

Нажатия на **L/R** показывают касание сенсора оранжевым свечением с плавным затуханием.
Джойстик показывает направление и центральное нажатие; его можно проверить мышью,
касанием или клавиатурой. Значок рядом с **Battery** переключает макет зарядки:
при подключении внутри батареи появляется молния.

## Локальный запуск

Готовый `index.html` можно открыть браузером без установки инструментов.
Для изменения исходников нужен [Node.js 22 LTS](https://nodejs.org/en/download):

```sh
npm ci
npm run dev
```

Сборка автономной страницы:

```sh
npm run build
```

Команда проверяет TypeScript, собирает приложение и обновляет `index.html`
в корне репозитория. Сборка работает самостоятельно, без прошивки и SDK.

## Состав

- `src/index.html`, `src/main.ts`, `src/styles.css` — исходники макета;
- `scripts/publish-standalone.mjs` — упаковка JS/CSS в один HTML, без сетевой публикации.

В публичный репозиторий не входят прошивки, SDK, ключи, внутренние документы и
журналы устройств. Выбранный в макете файл остаётся в браузере и никуда не передаётся.

## Публикация

После `npm run build` сохранить исходники и обновлённый `index.html` в одном коммите.
GitHub Pages публикует корень ветки `main`; сборка сама ничего не отправляет в GitHub.
README ведёт на последнюю опубликованную версию, локальные правки видны после публикации.

Исходники библиотеки связи разрабатываются в закрытом репозитории.
В публичном репозитории допустим только её собранный модуль без source map.
